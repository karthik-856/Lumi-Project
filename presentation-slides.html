Problem Definition: The "Blank Slate" Barrier

Why Novice Users and Students Struggle with Generative AI

The Real User Problem

  • Blank Slate Syndrome: Users face an empty text box with no structural cues.
  • The Jargon Wall: Terms like few-shot, system roles, and delimiters confuse non-technical users.
  • Vague In, Vague Out: Novice 1-sentence inputs produce 10-page irrelevant outputs.
  • HCI Relevance: Severe failure in Norman's Gulf of Execution.

Target User Groups

  • University Students: Needing structured study plans, concept breakdowns, and quiz prompts.
  • Non-Technical Writers: Drafting formal emails, project reports, and meeting summaries.
  • Diverse & Accessibility Learners: Users requiring high contrast, font scaling, vestibular safety, and complete offline privacy.

Design Concept: Interactive Scaffolding

Working Prototype at http://localhost:4731 (Built with React 19 + FastAPI)

Interactive Prompt Workbench

  • Immediate Home Scaffold: No empty page — presets for Study, Presentation, and Code.
  • Synchronous Generation: Changing an Audience or Tone dropdown updates the prompt in real time.
  • Live Heuristic Scoring: 0–100 quality indicator updates instantly with zero server round-trips.
  • 1-Click Actions: Copy prompt, Continue in Studio, or inspect in Prompt Analyzer.

Core Novelty & Philosophy

  • Local-First Architecture: Zero data sent to outside cloud models — complete privacy.
  • Scaffolding Over Automation: Teaches users why instructions work rather than behaving as a black-box generator.
  • Explainable Heuristic Engine: 7 weighted dimensions (Clarity, Specificity, Context, Audience, Output, Limits, Examples).

Hierarchical Task Analysis (HTA)

Decomposing Prompt Formulation into 6 Cognitive Decision Steps
Step 1 & 2

Idea & Goal

  • Idea (The Task): User inputs raw intent in natural language; engine cleans filler phrases.
  • Goal (The Role): Selects agent persona: Learn, Create, Analyze, Write, Solve.
Step 3 & 4

Audience & Context

  • Audience (Depth): Chooses reader level: Me, Student, Teacher, Professional.
  • Context (Grounding): Scaffolds situation, current knowledge, and specific course needs.
Step 5 & 6

Tone & Output

  • Tone (Voice): Selects linguistic style: Simple, Academic, Friendly.
  • Output (Structure): Physical format: Step-by-step, Bullets, Table, Code.

HCI Theoretical Grounding

Three Established HCI Frameworks Mapped to Concrete UI Elements

Norman's Gulfs

  • Gulf of Execution: Bridged by structured choice cards replacing free-form prompt syntax.
  • Gulf of Evaluation: Bridged by 7-dimension scoring radar and "Why?" cognitive accordions.

Nielsen's Heuristics

  • #1 System Status: Live prompt canvas and real-time score indicators update on keystroke.
  • #6 Recognition > Recall: Options for Tone, Audience, and Format eliminate memorization.
  • #8 Minimalist Design: One question per step; advanced options hidden via progressive disclosure.

Shneiderman's Rules

  • Informative Feedback: Visual score bands (Needs guidance → Excellent) and improvement tags.
  • Reduce Memory Load: Complete assembled prompt visible at all times on the side canvas.

Inclusive Design & Accessibility

WCAG 2.1 AAA Compliance, Cognitive Ergonomics & Equity

Perceptual Accessibility

  • High-Contrast Theme: Custom high-ratio borders and distinct focus rings.
  • Dynamic Text Scaling: Default (16px), Large (18px), and Larger (20px) font scaling across the entire UI.
  • Vestibular Protection: Native prefers-reduced-motion integration eliminates disorienting animations.
  • Semantic ARIA: Full keyboard navigation, live regions, and screen-reader support.

Cognitive & Socio-Economic Equity

  • Low Cognitive Load: Single-decision step flow prevents sensory and decision fatigue.
  • Zero Jargon: Plain language prompts with transparent explanations for every decision.
  • Zero Cost Barrier: Runs 100% locally in browser; students without paid LLM subscriptions or developer API keys are not excluded.

Evaluation Plan: Built-in Comparative Study

Within-Subjects Protocol Implemented at http://localhost:4731/evaluate

Experimental Design

  • Condition A (Unaided): User writes prompt in raw input box with zero scaffolding.
  • Condition B (Guided): User writes same task using Lumi's 6-step structured studio.
  • Standardized Task: Academic exam study guide formulation.
  • Data Export: Built-in .json and .csv reporting for immediate statistical analysis.

Empirical Dependent Metrics

  • Prompt Quality: Deterministic 0–100 score across 7 dimensions (Clarity, Context, Output, etc.).
  • Time-on-Task & Revisions: Automated millisecond duration and edit count tracking.
  • Self-Efficacy: Pre/post Likert confidence scale (1 to 5).
  • Usability Scale: 5-item standardized Likert survey (Ease, Clarity, Transparency, Confidence, Reuse).
  • Preliminary Result: Average quality gain of +30 to +37 points.

Expected Impact, Ethics & Limits

Educational Empowerment, Data Sovereignty & System Scope

Expected Impact & Ethics

  • Pedagogical Literacy: Transforms users from passive consumers into confident, critical prompt authors.
  • Absolute Data Sovereignty: No prompt logging, tracking, or cloud leakage — 100% user data control.
  • Ethical Scoring: Heuristics framed as formative educational guidance, not normative grades.

Current Limitations

  • Rule-Based Boundaries: Employs deterministic regex heuristics rather than deep semantic validation.
  • Linguistic Focus: Currently optimized for English grammatical and syntactic structures.
  • Pre-Generation Scope: Scaffolds the prompt instruction; does not score model response output.
